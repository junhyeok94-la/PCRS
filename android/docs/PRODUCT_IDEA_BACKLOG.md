# 후속 제품 아이디어

## 아침의 가벼운 오늘의 운세

사용자 제안: 출근 전 날씨·복장을 확인하는 아침 흐름에 재미 요소로 오늘의 운세나 사주 관련 콘텐츠를 제공한다.

현재 상태: **기획 후보로 기록, 구현·출생정보 수집은 시작하지 않음.** 첫 실행 입력이나 현재 날씨·의상 추천 개발 범위를 늘리지 않는다.

검토 방향:

- 홈의 날씨·복장 결정을 끝낸 뒤 스크롤 아래의 작은 선택 카드로 제공하는 안. 기본 화면의 핵심을 가리지 않는다.
- 생년월일 없이 같은 날 같은 내용으로 제공하는 가벼운 운세와, 개인 출생정보를 사용하는 콘텐츠를 별도 안으로 비교한다.
- 생년월일만 입력받은 기능을 ‘정밀한 사주 분석’으로 포장하지 않는다. 필요한 정보·콘텐츠 제공 방식·라이선스·비용을 먼저 검토한다.
- 오락용임을 분명히 하고 날씨·건강·안전·금융 판단이나 실제 의상 추천 보정에는 사용하지 않는다. 행운의 색 같은 꾸미기 제안도 날씨에 맞는 옷의 종류·보온을 바꾸지 않는다.
- 개인형을 채택한다면 목적·선택성·저장 위치·삭제 방법을 정한 뒤 필요한 최소 정보만 요청한다. 정확한 생년월일을 알림·로그·광고 요청에 자동 포함하지 않는다.
- 채택 시 일자·콘텐츠 버전별로 캐시하며 화면을 열 때마다 외부 생성 API를 호출하지 않는다. 실패해도 날씨·추천 화면은 정상 사용 가능해야 한다.

판단 시점: 출퇴근·민감도 설정과 구조화 피드백의 핵심 흐름을 먼저 구현한 뒤, 화면 정보량과 재방문 가치·운영 부담을 비교한다. 현재 우선순위는 보류다.
