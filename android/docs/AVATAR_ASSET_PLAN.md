# 3D 토이 아바타 제작 검증안

현재 구현: [완성 착장 8종의 앱 연결과 검증](AVATAR_ASSET_IMPLEMENTATION_STATUS.md)을 우선한다. 아래 다섯 착장 후보는 초기 계획이며, 실제 제작은 현재 추천 규칙의 조합에 맞춰 진행했다. 니트 단독·반팔+가디건 등 미사용 조합을 전부 제작했다는 의미는 아니다.

후속 검증: 두 착장의 투명 이미지를 생성하고 API 37 Android에서 겉옷 전환·명암 배경·표시 크기를 확인했다. [검증 결과](../design/validation/README.md)와 [제품 개발 검토](PRODUCT_TECH_REVIEW.md)를 우선한다. 아래 다섯 착장 전체나 외형 꾸미기를 검증한 것은 아니다.

2026-11-02. 사용자가 선택한 것은 3D 토이의 시각 스타일이다. 실시간 3D 엔진·모델·리깅 도입을 확정하지 않았다. 현재 승인된 이미지는 합쳐진 디자인 시안이며 몸체·머리·옷의 분리된 제작 자산이 아니다.

## 초기 제작 방식 제안

첫 검증은 **완성된 전신 차림 이미지 전환**으로 한다. 고정된 인물·자세의 소수 착장을 준비하고 추천 범주에 맞는 이미지를 보여준다. 신체와 옷을 매번 AI로 실시간 생성하거나, 완성 이미지 위에 다른 옷을 임의로 겹치지 않는다. 이 방식은 렌더 이미지를 앱에 보여주므로 시각 스타일과 앱 구현 부담을 분리해 검증할 수 있다. 아직 확정한 구현 방식은 아니다.

장점은 승인된 그림의 품질을 유지하기 쉽다는 것이다. 제약은 새로운 착장마다 일관된 추가 이미지가 필요하고, 임의의 상하의 조합·헤어·체형을 자유롭게 섞을 수 없다는 것이다. 꾸미기 옵션을 늘리면 착장×외형의 이미지 수가 늘어난다. 이를 해결하기 전 대규모 아바타 꾸미기를 약속하지 않는다.

## 검증용 최소 착장 세트

| 자산 ID | 실제 입은 모습 | 사용 목적 |
|---|---|---|
| cotton-long | 얇은 긴팔·긴바지, 겉옷 없음 | 출근 도보·재킷 휴대 |
| cotton-jacket | 위 차림+가벼운 재킷 | 귀가·재킷 착용 |
| knit-single | 중간 두께 긴팔 니트·긴바지 | 겉옷 없는 대안 |
| tee-short | 반팔·긴바지, 겉옷 없음 | 가디건 휴대·탈착 |
| tee-cardigan | 위 반팔+가벼운 가디건 | 가디건 착용 |

이 다섯 자산은 제작해야 할 후보이며 현재 모두 개별 투명 이미지로 준비된 것은 아니다. 코트·반바지·스커트·두꺼운 겨울옷 등 지원 범위를 다섯 개로 대체하지 않는다. 날씨에 맞는 지원 착장이 없으면 범주 텍스트·의류 그림을 우선 제공하고 잘못된 아바타를 보여주지 않는 대체 표현이 필요하다.

## 자산 합격 기준

- 얼굴·헤어·피부 톤·몸 비율·손·신발·카메라·자세·발 기준선이 같아야 한다. 다른 인물처럼 보이는 결과는 채택하지 않는다.
- 상의 면/니트와 재킷/가디건의 실루엣·칼라·두께가 휴대폰에서 구분되어야 한다. 색만 바꾸어 옷 차이를 표현하지 않는다.
- 재킷을 입지 않은 자산에는 재킷 소매·칼라·그림자가 남지 않아야 한다. 겉옷 휴대와 실제 착용을 구분한다.
- 실제 배치에서 전신 높이 약 240~320dp와 작은 대안 미리보기 모두 확인한다. 최종 치수는 실제 화면 배치로 정한다.
- 투명 배경과 깨끗한 가장자리, 동일 캔버스·여백, 잘리지 않은 손발, 밝고 어두운 배경에서의 외곽을 확인한다. 그림자와 배경이 인물에 합쳐져 있으면 분리 제작한다.
- 내보낼 파일 형식·해상도·용량은 기기 성능과 화면 배율을 확인해 정한다. 현재의 큰 PNG 시안을 그대로 제품 자산으로 배포하지 않는다.
- 각 그림은 clothing category/thickness와 연결된 명세를 가져야 한다. 추천 결과와 다른 두께·소재가 보이는 그림을 임의로 연결하지 않는다.
- 접근성 설명은 외모 나열보다 입은 의류와 겉옷 상태에 초점을 맞춘다. 외형은 체감 민감도나 성별을 자동 결정하지 않는다.

## 의류·외형의 확장 결정

기본 캐릭터 하나로 착장 전환이 만족스러운지 먼저 확인한 뒤 피부 톤·헤어 옵션을 확장한다. 현재 UI의 꾸미기 진입은 방향 제안이며 실제 지원할 옵션과 제작량은 미확정이다. 신체 데이터로 외형을 자동 재현하지 않는다. 장기적으로 3D 모델/리깅 렌더 또는 전문 일러스트 제작을 선택할 수 있으나 지금 도입하지 않는다.

제작 부담·착장 식별성·다른 모습의 대표성 중 하나가 충족되지 않으면 꾸미기를 줄이거나 의류 그림 중심 대체 표현을 검토한다. 기존의 단순 CSS 아바타를 승인된 품질의 대체재로 사용하지 않는다.

## 다음 단계의 완료 조건

같은 인물의 다섯 착장 중 최소 한 쌍에서 겉옷 ON/OFF를 교체해 보고, 사용자에게 같은 인물로 보이는지·옷 차이가 읽히는지 확인한다. 배경·작은 크기·대안 미리보기·오프라인 로딩을 확인한다. 사용자 승인과 제작량 평가가 끝나기 전 ‘아바타 구현 검증 완료’로 표시하지 않는다.
