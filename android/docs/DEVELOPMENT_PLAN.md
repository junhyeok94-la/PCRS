# Android 기능별 개발 계획

> 초기 골격 단계의 후보·APP-00 검증 이력입니다. 현재 범위와 순서는 [개발 계획 v0.4](DEVELOPMENT_PLAN_V0_4.md)를 우선합니다. 아래 옷장·활동 점수·계정 항목은 현재 첫 버전의 확정 범위가 아닙니다.

기준일: 2026-11-01. 기존 웹의 기능 구현 여부와 Android 진행 상태는 별개로 관리합니다.

현재는 [제품 기획 인터뷰](PRODUCT_PLANNING.md)를 진행 중입니다. 아래 기능 목록과 순서는 후보이며, 제품 기획·와이어프레임·UI 디자인·개발 명세를 정리한 후 최종 확정합니다. 그전에는 앱 기능 구현을 진행하지 않습니다.

## 개발 방식

1. 한 번에 한 기능의 입력, 화면, 저장 범위, 실패 처리를 정합니다.
2. 해당 기능만 구현하고 기기에서 사용자 흐름을 검증합니다.
3. 검증 결과를 기록하고 완료 조건이 충족되면 다음 기능으로 넘어갑니다.

실제 날씨가 필요한 단계에서는 데이터 공급자 장애를 임의의 예보로 대체하지 않습니다. UI 개발용 샘플을 쓴다면 개발 환경에서만 명시적으로 구분합니다.
