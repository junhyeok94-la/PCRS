# 아바타 착장 확장 결과

후속 M5: [출퇴근·성향 규칙](PERSONALIZATION_IMPLEMENTATION_STATUS.md)에서 얇은 기본 차림에 재킷을 휴대하는 두 조합을 추가 매핑했다. 이미지 수는 8종 그대로이며 정확히 대응하는 의류·착용 상태 조합은 현재 12개다. 아래 10개 조합은 M4 완료 당시 기록이다.

2026-11-02. 기존 두 이미지에 새 착장 6종을 추가해 **기본 캐릭터 1종·완성 착장 8종**을 앱에 연결했다. 현재 지역 기본 추천의 모든 기본 차림과 가디건 대안에 대응한다. 추천 규칙 자체는 변경하지 않았다.

## 지원 범위

| 이미지 | 실제 의류 구성 |
|---|---|
| 기존 긴팔 | 얇은 긴팔·일반 긴바지·겉옷 없음. 재킷/가디건 휴대에 사용 |
| 기존 재킷 | 얇은 긴팔·일반 긴바지·가벼운 재킷 착용 |
| 새 가디건 | 얇은 긴팔·일반 긴바지·얇은 가디건 착용 |
| 새 얇은 긴팔 | 얇은 긴팔·얇은 긴바지·겉옷 없음 |
| 새 반팔 | 얇은 반팔·얇은 긴바지·겉옷 없음 |
| 새 중간 재킷 | 중간 두께 니트·일반 긴바지·중간 두께 재킷 |
| 새 코트 | 중간 두께 니트·보온 긴바지·보온 코트 |
| 새 패딩 | 보온 내의+니트·보온 긴바지·두꺼운 패딩 |

휴대 상태에 입은 그림을 쓰지 않는다. 추천의 상의·하의·겉옷·상태가 모두 일치해야 이미지가 선택된다. 종류나 두께가 다른 임의 조합은 여전히 의류 구성으로 대체 표시한다. 이미지 파일을 늘렸다는 이유로 추천이 다른 옷을 선택하지 않는다.

UI 리소스 연결은 `core/ui/AvatarResources.kt`, 의류 조합 연결은 `core/recommendation/OutfitEngine.kt`에서 분리한다. `OutfitCard`는 연결된 이미지만 표시한다.

## 제작·파일

내장 **image_gen** 도구의 이미지 편집으로 기존 재킷 착장을 참조해 의류를 바꿨다. 별도 유료 API/CLI를 사용하거나 키를 요청하지 않았다. 원본 생성 파일은 기본 생성 폴더에 보존하고, 앱이 사용하는 사본을 `app/src/main/res/drawable-nodpi/avatar_outfit_*_v1.png`에 저장했다. 기존 두 이미지를 덮어쓰지 않았다.

- [검토 갤러리](../design/avatar-assets-v1/index.html)
- [최종 프롬프트 6종](../design/avatar-assets-v1/prompts.json)
- [생성 파일 이력](../design/avatar-assets-v1/generation.json)
- [파일 해시·캔버스·알파·발 기준선](../design/avatar-assets-v1/manifest.json)

8장 모두 1024×1536 RGBA다. 알파 128 기준 발 끝은 y=1463 전후 2픽셀 안에 있고 손발이 잘리지 않았다. 가장자리 알파 최대 1/255를 허용한 점검을 통과했다. 이는 그림을 재편집해 완전 0으로 만든 것이 아니며, 실제 밝고 어두운 배경에서 외곽도 확인한다. 얼굴·머리·자세는 시각적으로 맞췄으나 픽셀 단위 동일성을 보장하는 3D 리깅 자산은 아니다. 가디건의 머리 상단은 기존보다 약 13픽셀 높아 미세한 생성 차이는 남는다.

## 검증과 한계

- 단위 테스트: 기존 날씨 13개 + 추천·자산 연결 18개, 총 31개. 현재 규칙의 모든 출력과 대안, 겉옷 착용/휴대 차이, 하의 두께 차이를 확인한다. 가능한 216개 조합 중 지원하는 10개만 매핑하고 나머지는 대체 이미지로 위장하지 않는 것을 확인한다.
- 디버그·릴리스 빌드와 lint 통과. lint 오류 0, 기존 경고 12개.
- API 37의 디버그 전용 검증 화면에서 9개 상태(휴대 포함)를 실행했다. 이 화면은 가상 날씨를 제품 홈에 주입하지 않으며 릴리스에 포함하지 않는다.
- [실제 화면과 검증 기록](../design/avatar-assets-v1/README.md)을 별도로 보존한다.

자유로운 상하의 조합·체형·헤어·성별·피부색 꾸미기·실시간 3D·상의나 바지 종류 전체 지원은 범위 밖이다. 그림은 종류와 레이어를 전달하는 표현이며 실제 원단 두께·보온 성능을 측정한 것이 아니다. 개인 추천 효과, 실기기 성능, 모든 Android 버전의 표시 검증도 남아 있다.

다음 개발 단위는 **M5 선택 출퇴근·민감도 설정**이다. 사용자가 설정한 장소와 출발 시각을 기준으로 실제 예보를 비교하고, 공통 기본 차림과 시간별 겉옷 입기/휴대를 계획한다. 초기 실행은 여전히 지역 하나로 시작한다.
