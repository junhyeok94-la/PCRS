# 기본 추천 구현 결과

후속 진행: [아바타 착장 8종](AVATAR_ASSET_IMPLEMENTATION_STATUS.md)으로 확장했다. 아래는 2종 연결 당시의 기록이다. 현재 규칙이 만드는 기본 차림·가디건 대안은 모두 아바타로 표시하며, 개인화·피드백은 여전히 남아 있다.

2026-11-02. M3 지역 기본 추천 규칙을 홈에 연결했다. M4는 **기존 두 착장과 정확히 일치하는 범위의 연결**까지 구현했다. 반팔·니트·가디건·코트·패딩 자산 제작은 남아 있다. 개인 최적화 효과를 검증하거나 전체 아바타를 완성한 상태가 아니다.

## 현재 동작

- 실제 선택 지역의 예보 시각 3개를 선택해 상의·하의·겉옷과 입기/챙기기를 확인한다. 출퇴근 설정이 없으므로 ‘출근/귀가’로 가정하지 않는다.
- 기본 차림·기온·예보 시각·지역 기준을 먼저 표시한다. 추천 이유와 규칙 버전·자료 부족·기온 변화 설명은 ‘왜 이 차림인가요?’에서 펼친다.
- 비·눈·바람·습도 안내는 작은 아이콘과 문구로 제공한다. 개인 체감·걷기·실내 환경을 자동 추정하지 않는다.
- 조건에 맞으면 가디건 대안을 제공한다. 탐색 선택은 후보 확정·실제 착장·피드백 저장으로 처리하지 않는다. 새 예보에서 대안 조건이 사라지면 기본 차림으로 복귀한다.
- 아바타는 추천 의류와 일치할 때만 표시한다. 휴대하는 재킷은 입히지 않는다. 미지원 의류는 구성 정보로 보여준다.
- 예보·기온 누락 시 해당 시각의 추천을 만들지 않는다. 이전 자료의 추천은 별도로 표시하며 날씨 보존 한계를 넘기면 사용하지 않는다.

[기준표·근거·제약](RECOMMENDATION_RULES_V0_1.md)의 regional-0.1은 초기 평가용 휴리스틱이다. 개인에게 맞는 추천인지 검증하는 피드백 기능은 후속 작업이다.

## 검증

- 실제 API 37 에뮬레이터에서 강남구 15시 15도 재킷 차림, 21시 8도 보온 차림과 가디건 대안을 확인했다. 수치는 촬영 당시 예보다.
- 320dp 폭·글꼴 1.3·다크 모드에서 추천과 아바타를 확인했다. 이전 예보 안내가 표시되는 상태도 확인했다.
- 테마 변경과 로컬 서버 중단에 따른 갱신 실패 후에도 21시 선택·추천 근거 펼침이 유지되는 것을 확인했다. 서버 중단 후에는 추천에도 이전 예보 표시가 추가됐다. 검증 후 서버와 기기 설정은 복구했다.
- 자동 테스트: 기존 날씨 계약 13개 + 추천 경계 15개. 기온 경계, 19도에서 재킷 휴대, 강수 형태/확률, 누락과 0, 잘못된 수치, 정확한 시각·다음 시간부터 시작하는 예보·날짜 넘김, 실황만 있는 경우, 이전/만료 예보, 대안 제외, 아바타 착용 일치를 검증한다.
- 디버그·릴리스 빌드와 단위 테스트 28개 통과. lint 오류 0·경고 12개. 새로운 SDK·라이브러리·서버 엔드포인트는 추가하지 않았다.
