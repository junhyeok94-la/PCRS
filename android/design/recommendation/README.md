의상 추천은 **지역·시각 기준의 초기 규칙**이다. 개인의 민감도·출퇴근·실내 환경은 아직 반영하지 않는다. 캐릭터는 일치하는 두 착장만 지원한다. 나머지 의류는 설명과 중립 심벌로 표시하며 아바타 확장 작업이 남아 있다.

기본 캡처 1080×2400 / density 420. 작은 화면 840×1867 / density 420. 검사 후 화면·글꼴·테마 설정은 원래대로 복원했다. 초기 캡처 뒤 설명 문법과 상태 보존을 보완했고 최종 앱에서 추천 근거를 다시 확인했다.
