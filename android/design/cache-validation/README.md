# 날씨 영속 캐시 실제 앱 확인

실제 기상청 자료를 받은 API 37 Android 앱으로 확인했다. 검증 지역은 기존 저장 설정인 서울특별시 관악구이며 임의 예보를 주입하지 않았다.

1. [최초 온라인 홈](first.png): 예보·실황 수집과 앱 전용 JSON 스냅샷 생성 확인. 현재 실황 1페이지+예보 2페이지로 HTTP 시도 3회였다.
2. [서버를 끄고 앱 강제 종료·재실행](offline-restart.png): 디스크에 남은 유효 자료로 홈 복원. 유효한 캐시는 서버를 다시 조회하지 않았다.
3. [오프라인 수동 새로고침](offline-refresh.png): 실패 안내와 이전 자료 표시, 가상 날씨 대체 없음.
4. [서버를 재시작한 뒤 갱신](recovered.png): SQLite 자료로 복구. 상류 요청 집계는 3회 그대로이며 실제 발표·수신 시각도 유지됐다.

[요청 집계와 자료 시각](live-check.json), 각 화면의 UI 계층 XML을 함께 보존했다. 촬영 당시 자료이며 최신 날씨 안내용이 아니다. 기존 에뮬레이터의 상태 표시줄은 GMT, 앱 날씨 시각은 KST다.

초기 실조회에서 만료 시각의 소수 초 절삭을 발견해 이후 코드에서는 다음 제공 예정 시각과 정확히 일치하도록 보완했다. 위 live-check는 보완 전 수집된 자료의 시각을 그대로 보존한 기록이다. 정확한 만료 경계는 자동 테스트로 검증했다.

[캐시 구현·제약·최종 테스트](../../docs/CACHE_IMPLEMENTATION_STATUS.md). 검증 뒤 이번에 시작한 서버·에뮬레이터·빌드 데몬을 다시 종료했다.
