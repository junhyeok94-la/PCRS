# 출퇴근·선택 성향 실제 앱 검증

2026-11-02, M5. 정적 디자인 시안이 아닌 실제 Android 디버그 앱의 에뮬레이터 캡처다. 개인에게 최적화되었다는 효과 검증은 아직 없다.

검증용 설정은 집 서울특별시 / 직장 서울특별시 강남구, 화요일 09:30 출근·18:00 귀가, 추위·더위 모두 많이 탐, 도보 10분 이내·대중교통·서늘한 실내다. 기존 기준 지역 서울특별시 관악구와 별도로 저장했다. 테스트 후 검증용 개인 설정만 제거하고 기존 기준 지역을 보존했다.

## 검증 결과와 한계

- Android 단위 테스트 61개, 실패 0. 디버그·릴리스 빌드 성공. lint 오류 0, 기존 경고 12개.
- 미설정 보존, JSON 복원, 독립 성향 조합, 날짜·요일·자정 넘김, 과거/누락 예보, 정확한 의류와 이미지 매핑, 두 지역 요청·부분 응답·캐시 재사용을 자동 검증했다.
- 실제 UI에서 입력·취소·저장·재실행·출근/귀가·지역 전환·작은 화면을 확인했다. 민감도만 변경해 저장했을 때 서버의 기상청 HTTP 시도 집계는 10회에서 10회로 유지됐다.
- 개인 설정은 서버로 전송하지 않는다. 두 지역 조회는 유효한 지역 캐시를 제외하고 필요한 지역만 묶는다.
- 에뮬레이터 상태 표시줄 시각은 호스트 한국 시각과 다를 수 있다. 일정 계산과 앱의 예보 표시는 한국 시간대다.
- 전체 제품 접근성·TalkBack·실기기·스토어 배포 검증은 남아 있다. 모든 기온 차이에 대해 하나의 종일 착장을 계산하거나 실제 체감을 학습하지 않는다.

세부 정책은 [구현 결과](../../docs/PERSONALIZATION_IMPLEMENTATION_STATUS.md)를 따른다. 다음은 M6 실제 차림·더움/추움·강도·상황·예보 불일치를 구분한 피드백 기록이다.
